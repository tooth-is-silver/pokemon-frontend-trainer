# Pokemon JS Trainer Planning Draft

## 1. Goal

- `ko.javascript.info` 기반으로만 자바스크립트 코어 질답을 제공한다.
- 사용자는 문제를 풀며 포켓몬을 육성하고, 진화와 도감 수집을 진행한다.
- 초기 목적은 `개인용 + 제한적 공유`다.

## 2. Core Principles

- 답변과 해설은 반드시 `ko.javascript.info` 근거가 있어야 한다.
- 근거가 없으면 AI가 추측하지 않는다.
- 학습 엔진과 포켓몬 테마는 분리한다.
- 게임 요소는 학습을 보조해야 하고, 보상을 남발하지 않는다.

## 3. MVP Scope

- 문제 출처: `ko.javascript.info` 전체
- 문제 유형
  - 예/아니오
  - 오지선다
  - 빈칸 맞추기
- 포켓몬
  - 1세대 기준
  - 스타터: 이상해씨, 파이리, 꼬부기
  - 최초 스타터 선택 화면에서 1마리 선택
  - 이후 신규 포켓몬 선택은 중복 획득 가능
  - 진화 여부 직접 선택
- 도감
  - 일부 포켓몬부터 시작
  - 해금 시 도감 등록
- 아이템
  - 연속 정답 보상
  - 스탯 보조 효과만 제공

## 4. Learning Loop

1. 스타터 선택
2. 학습 주제 선택
3. 한 화면에서 문제 1개 풀이
4. 정답 여부 반영
5. 스탯/경험치/아이템 지급
6. 진화 조건 달성 시 진화 선택
7. 조건 충족 포켓몬 도감 등록
8. 최종 진화 후 졸업 조건을 채운 상태에서 다음 정답을 맞히면 신규 포켓몬 선택 가능

## 5. Content Policy

### 5.1 Answer Guardrails

- 모델은 검색된 문서 조각만 보고 답한다.
- 모든 응답은 출처 페이지를 연결한다.
- 문서에 없는 내용은 `해당 사이트 기준으로 확인되지 않음` 처리한다.
- 질문은 길게 설명하지 않고 퀴즈형 문장으로 짧게 제시한다.

### 5.2 Question Data Shape

```json
{
  "id": "this-001",
  "topic": "this",
  "type": "yes_no",
  "prompt": "화살표 함수는 자신만의 this를 가진다.",
  "answer": false,
  "choices": [],
  "sourcePage": "https://ko.javascript.info/object-methods",
  "sourceTitle": "메서드와 this",
  "sourceExcerpt": "화살표 함수는 자신만의 this를 가지지 않는다.",
  "acceptedAnswers": [
    "아니오"
  ],
  "forbiddenInference": [
    "source에 없는 추가 개념으로 정답 처리 금지"
  ]
}
```

### 5.4 Question Writing Rules

- 질문은 짧고 바로 답할 수 있어야 한다.
- 한 문항에는 하나의 핵심 개념만 담는다.
- 문항 길이는 가능한 한 짧게 유지한다.
- 긴 설명형 질문보다 퀴즈형 문장으로 변환한다.
- 사이트 전체를 출처로 쓰되, 각 문항은 반드시 특정 페이지 근거를 가진다.
- 한 페이지에서 여러 퀴즈를 생성할 수 있어야 한다.
- 문항 수는 페이지 내용량이 많을수록 더 많이 생성한다.
- 학습 UI에서는 한 번에 문제 1개만 보여준다.
- 빈칸 문제는 자유 해석하지 않고 `허용 답안 목록` 비교로 판정한다.
- 오지선다 문제의 오답 보기는 다른 문항의 정답 후보들 중에서 랜덤 추출한다.
- 단, 오답 보기는 같은 문제 타입과 비슷한 개념군 안에서만 추출한다.

## 6. Game Systems

### 6.1 Stats

- MVP 공통 스탯은 4개를 사용한다.
- `hp`
- `attack`
- `defense`
- `speed`
- 각 스탯 최대값은 `100`이다.

### 6.2 Reward Rules

- 기본 정답 보상은 작게 준다.
- 첫 정답 시 각 스탯 `+5`
- 같은 문제를 다시 맞히면 각 스탯 `+1`
- 같은 질문 반복 정답 시 보상을 낮춘다.
- 오답은 보상이 없다.
- 일반 성장과 진화는 `스탯` 기준으로 처리한다.
- 아이템은 `연속 정답 10개` 달성 시 지급한다.
- 아이템은 정해진 아이템 풀에서 랜덤으로 1개 지급한다.
- 아이템은 특정 스탯을 올리는 효과를 가진다.
- 아이템은 획득 즉시 자동 적용된다.
- 아이템 풀은 포켓몬 열매 이름을 사용한다.
- `hp`: `오랭열매`
- `attack`: `무화열매`
- `defense`: `나나열매`
- `speed`: `배리열매`
- 각 열매는 해당 스탯을 `+5` 올린다.

### 6.3 Evolution

- 진화는 `특정 스탯 기준`으로 연다.
- 조건 충족 시 즉시 자동 진화하지 않고 선택지를 보여준다.
- 진화를 보류하면 현재 형태 유지 + 이후 원하는 시점에 진화 가능하게 한다.
- 진화 연출은 전용 모달 또는 전용 페이지로 보여준다.
- MVP에서는 모든 포켓몬이 공통 스탯 구조를 사용하고, 이후 개별 조정한다.
- 2차 진화 포켓몬 기준
  - 1차 진화: `hp/attack/defense/speed`가 모두 `50` 이상
  - 2차 진화: `hp/attack/defense/speed`가 모두 `85` 이상
  - 졸업: `hp/attack/defense/speed`가 모두 `100`
- 1차 진화만 있는 포켓몬 기준
  - 진화: 4개 스탯 모두 `50` 이상
  - 졸업: 4개 스탯 모두 `100`
- 진화가 없는 포켓몬 기준
  - 4개 스탯 모두 `50` 이상이면 다음 포켓몬 선택 가능
- 최종 진화 후에는 졸업 조건까지 달성해야 다음 포켓몬 선택이 열린다.
- 졸업 조건 충족 상태에서 다음 정답을 맞히면 신규 포켓몬 선택 UI를 띄운다.

### 6.5 Pokemon Selection

- 최초에는 스타터 3마리 중 1마리만 선택 가능하다.
- 신규 포켓몬 선택 해금은 마지막 진화체에서 졸업 스탯을 모두 채운 뒤, 다음 정답을 맞히는 순간 열린다.
- 신규 포켓몬 선택 시 기본적으로 2마리 후보 중 1마리를 고른다.
- 포켓몬 중복 선택은 기본적으로 막는다.
- 선택 가능한 신규 포켓몬이 없을 때만 중복 선택을 허용한다.
- 이브이 같은 분기 진화 포켓몬을 고려해, 동일 포켓몬 복수 보유를 허용한다.
- 해금 시 선택 페이지 또는 모달을 띄워 신규 포켓몬을 선택하게 한다.
- 신규 포켓몬 후보는 아직 도감 등록이 안 된 포켓몬 중 랜덤 2마리로 구성한다.
- `파이어`, `썬더`, `프리저`, `뮤`, `뮤츠`는 일반 후보에서 제외한다.
- 선택 가능한 일반 포켓몬이 모두 소진된 이후에만 전설 포켓몬 선택창이 열린다.
- 전설 단계 1: `파이어`, `썬더`, `프리저`를 먼저 육성 대상으로 연다.
- 전설 단계 2: `파이어`, `썬더`, `프리저`를 모두 `100` 졸업시킨 뒤 `뮤츠` 선택 가능
- 전설 단계 3: `뮤츠`를 키운 뒤 `뮤` 선택 가능

### 6.4 Pokedex

- 포켓몬을 한 번이라도 획득하면 즉시 도감 등록
- 진화 시 진화한 형태도 별도 등록
- 챕터 클리어, 업적, 특정 연속 정답 조건으로 신규 포켓몬 해금
- 장기 목표는 1세대 도감 확장
- 전설 포켓몬은 일반 1세대 도감 완성 이후 별도 해금한다.

## 7. Architecture Direction

- 전체 문서 라우팅은 `docs/INDEX.md`를 기준으로 본다.
- 데이터 구조는 `docs/specs/data-structures.md`를 기준으로 구현한다.
- 게임 규칙은 `docs/specs/game-rules.md`를 기준으로 구현한다.
- 콘텐츠 규칙은 `docs/specs/content-rules.md`를 기준으로 구현한다.
- 화면 흐름과 UI 구조는 `docs/specs/screen-flow.md`를 기준으로 구현한다.
- 구현 순서는 `docs/implementation-roadmap.md`를 기준으로 진행한다.

```text
src/
  core/
    quiz/
    progression/
    evaluation/
  themes/
    pokemon/
  content/
    questions/
    sources/
  app/
```

- `core`: 문제 처리, 스탯, 진화 조건
- `themes/pokemon`: 이름, 이미지, 진화 라인, 아이템명
- `content`: 출처 문서와 문제 데이터

## 8. UI Direction

- 홈: 스타터 선택, 오늘의 학습 시작
- 학습: 포켓몬 이미지, 현재 스탯, 문제 1개, 빈칸 입력 또는 선택지
- 답변 직후 결과 페이지 없이 바로 다음 문제로 이동하고, 스탯은 즉시 갱신한다.
- 오답 시에는 현재 화면 하단에 정답, 짧은 해설, 출처 링크를 표시한다.
- 포켓몬: 현재 팀, 진화 가능 여부
- 도감: 해금 현황
- 선택: 최초 스타터 선택 화면, 이후 신규 포켓몬 선택 화면

## 9. Open Decisions

- 아이템 종류와 획득 확률, 상승 수치
- 친구 공유 범위를 어디까지 허용할지
- 포켓몬별 개별 스탯 규칙 조정표
- 오답 보기 후보를 묶는 개념군 규칙
- 전설 포켓몬 해금/선택/졸업 조건 상세
