# Game Rules

## 1. Stats

- 공통 스탯 4개 사용
- `hp`
- `attack`
- `defense`
- `speed`
- 각 스탯 최대값은 `100`

## 2. Rewards

- 첫 정답 시 각 스탯 `+5`
- 같은 문제 재정답 시 각 스탯 `+1`
- 오답은 보상 없음
- 일반 성장과 진화는 `스탯` 기준

## 3. Items

- `연속 정답 10개` 달성 시 열매 1개 지급
- 열매는 즉시 자동 적용
- 열매는 랜덤 지급
- 각 열매는 해당 스탯 `+5`

열매 매핑:

- `오랭열매`: `hp`
- `무화열매`: `attack`
- `나나열매`: `defense`
- `배리열매`: `speed`

## 4. Evolution

- 진화는 `특정 스탯 기준`으로 판정
- 조건 충족 시 학습 화면 위에 진화 모달을 표시한다.
- 진화 보류 기능은 MVP 범위에서 제외한다.

### 4.1 3단 진화

- 1차 진화: 4스탯 모두 `50` 이상
- 2차 진화: 4스탯 모두 `85` 이상
- 졸업: 최종 진화체에서 4스탯 모두 `100`

### 4.2 2단 진화

- 진화: 4스탯 모두 `50` 이상
- 졸업: 최종 진화체에서 4스탯 모두 `100`

### 4.3 무진화

- 4스탯 모두 `50` 이상이면 다음 포켓몬 선택 가능

## 5. Pokemon Selection

- 트레이너는 동시에 포켓몬 1마리만 보유한다. 중간 교체는 불가능하다.
- 최초에는 스타터 3마리 중 1마리 선택한다.
- **졸업 조건**
  - 다단 진화 종: 최종 진화체에서 4스탯 모두 `100`
  - 무진화 종: 4스탯 모두 `50`
- 졸업하면 **졸업 모달**이 학습 화면 위에 열린다.
- **후보 풀 룰**
  - 일반 wave: 미등록 일반 1세대 1차 진화체(또는 무진화 종) 중 랜덤 3마리.
  - 풀 크기 < 후보 수면 풀 그대로 노출.
  - 풀 크기 = 1이면 **선택창 없이 자동 해금** (안내만 보여주고 새 인스턴스로 즉시 시작).
  - 풀이 비면 다음 wave로 자동 전환. 풀 바닥 = 단계 종료 시점이라 후보 중복 허용 같은 fallback 룰은 두지 않는다.
- **이브이 정책**
  - 이브이 분기 진화 시 쥬피썬더/샤미드/부스터 중 유저가 직접 선택한다.
  - 도감 등록은 진화체 단위(샤미드·쥬피썬더·부스터 각각).
  - 이브이는 도감 미완성 분기가 남아 있는 한, 졸업 모달의 후보 풀에 다시 등장할 수 있다 (다른 분기 진화체 도감 채우기 위함).

## 6. Pokedex

- 한 번이라도 획득하면 즉시 도감 등록
- 진화한 형태도 별도 등록
- 장기 목표는 1세대 도감 확장

## 7. Legendary Rules

- 일반 wave 후보에서 항상 제외한다:
  - `프리저`
  - `썬더`
  - `파이어`
  - `뮤츠`
  - `뮤`

- 일반 1세대 도감(전설 5종 제외 146마리) 완성 시 전설 wave 1로 자동 전환한다.
- wave 1: `프리저`, `썬더`, `파이어`
  - 후보 풀이 `3 → 2 → 1`로 줄어들며 졸업 모달은 풀 크기 그대로 노출한다.
  - 풀이 1마리만 남으면 선택창 없이 자동 해금하고 새 인스턴스로 시작한다.
- wave 2: wave 1 모두 졸업 시 `뮤츠` 단독 후보로 자동 전환 (선택창 없음).
- wave 3: 뮤츠 졸업 시 `뮤` 단독 후보로 자동 전환 (선택창 없음).
- wave 3 종료(뮤 졸업) 시 엔딩 처리.
