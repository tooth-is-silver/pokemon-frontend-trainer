# Game Rules

## 1. Stats

- 공통 스탯 4개 사용
- `hp`
- `attack`
- `defense`
- `speed`
- 각 스탯 최대값은 `100`

## 2. Rewards

- 첫 정답 시 각 스탯 `+5`
- 같은 문제 재정답 시 각 스탯 `+1`
- 오답은 보상 없음
- 일반 성장과 진화는 `스탯` 기준

## 3. Items

- `연속 정답 10개` 달성 시 열매 1개 지급
- 열매는 즉시 자동 적용
- 열매는 랜덤 지급
- 각 열매는 해당 스탯 `+5`

열매 매핑:

- `오랭열매`: `hp`
- `무화열매`: `attack`
- `나나열매`: `defense`
- `배리열매`: `speed`

## 4. Evolution

- 진화는 `특정 스탯 기준`으로 판정
- 조건 충족 시 자동 진화하지 않고 선택지 제공
- 진화 보류 가능

### 4.1 3단 진화

- 1차 진화: 4스탯 모두 `50` 이상
- 2차 진화: 4스탯 모두 `85` 이상
- 졸업: 최종 진화체에서 4스탯 모두 `100`

### 4.2 2단 진화

- 진화: 4스탯 모두 `50` 이상
- 졸업: 최종 진화체에서 4스탯 모두 `100`

### 4.3 무진화

- 4스탯 모두 `50` 이상이면 다음 포켓몬 선택 가능

## 5. Pokemon Selection

- 트레이너는 동시에 포켓몬 1마리만 보유한다. 중간 교체는 불가능하다.
- 최초에는 스타터 3마리 중 1마리 선택한다.
- 최종 진화체가 4스탯 100을 채워 졸업하면 **졸업 모달**이 학습 화면 위에 열린다.
- 졸업 모달에는 후보 카드(이미지 + 이름) 3장을 표시하고, 1마리를 선택하면 새 인스턴스가 시작된다.
- 일반 wave 후보 풀: 미등록 일반 1세대 포켓몬 중 랜덤 3마리.
- 후보 풀 크기보다 후보 수가 작으면 풀 그대로 노출한다 (예: wave1 마지막 1장).
- 풀이 비면 다음 wave로 자동 전환한다 (정상 진행에서 풀 바닥 = 단계 종료 시점이므로 fallback 룰은 둔다).
- 이브이 분기 진화 시 쥬피썬더/샤미드/부스터 중 유저가 직접 선택한다.
- 이브이 계열에 한해 동일 종 복수 보유를 허용한다 (분기 진화 정책).

## 6. Pokedex

- 한 번이라도 획득하면 즉시 도감 등록
- 진화한 형태도 별도 등록
- 장기 목표는 1세대 도감 확장

## 7. Legendary Rules

- 일반 wave 후보에서 항상 제외한다:
  - `파이어`
  - `썬더`
  - `프리저`
  - `뮤츠`
  - `뮤`

- 일반 1세대 도감(146마리) 완성 시 전설 wave 1로 자동 전환한다.
- wave 1: `프리저`, `썬더`, `파이어`. 후보 풀이 3 → 2 → 1로 줄어들며 졸업 모달은 풀 크기 그대로 노출한다.
- wave 2: 위 3마리 모두 졸업 시 `뮤츠` 단독 후보로 전환한다.
- wave 3: 뮤츠 졸업 시 `뮤` 단독 후보로 전환한다.
- wave 3 종료(뮤 졸업) 시 엔딩 처리한다.
