# Game Rules

## 1. EXP

- 포켓몬 진행도는 단일 값 `exp`를 사용한다.
- `exp` 최대값은 `100`이다.
- 기존 4스탯 데이터가 남아 있는 경우 `hp`, `attack`, `defense`, `speed` 중 가장 높은 값을 `exp`로 마이그레이션한다.

## 2. Rewards

- 첫 정답 시 `exp +5`
- 같은 문제 재정답 시 `exp +1`
- 정답 보상은 현재 성장 경계(`50` → `85` → `100`)까지만 오른다.
- 오답은 보상 없음
- 일반 성장과 진화는 `exp` 기준

## 3. Items

- `연속 정답 10개` 달성 시 열매 1개 지급
- 열매는 즉시 자동 적용
- 열매는 랜덤 지급
- 열매 효과는 `exp +5`
- 열매 효과는 정답 보상과 별개이며, 성장 경계가 아니라 `exp` 최대값 `100`만 따른다.

열매 종류:

- `오랭열매`
- `무화열매`
- `나나열매`
- `배리열매`

## 4. Regions

- 포획형 전환의 기본 진입점은 지역 화면이다.
- 지역은 도감 등록 수에 따라 순차 해금한다.
- 지역 탐색의 기본 조우 확률은 `50%`다.
- 지역별 해금 조건:
  - `초록 평원`: 기본 해금
  - `물안개 해안`: 도감 5마리
  - `용암 동굴`: 도감 12마리
  - `달그림자 폐허`: 도감 20마리
  - `얼음 궁전`: 도감 35마리
  - `현대 도시`: 도감 50마리
- 지역별 출현 목록과 희귀도 확률은 [지역별 조우 정책](./region-encounters.md)을 따른다.
- 몬스터볼, 포획 확률, 포켓몬 패시브 효과는 후속 단계에서 연결한다.

## 5. Evolution

- 진화는 `exp` 기준으로 판정
- 조건 충족 시 학습 화면 위에 진화 모달을 표시한다.
- 진화 보류 기능은 MVP 범위에서 제외한다.

### 5.1 3단 진화

- 1차 진화: `exp 50` 이상
- 2차 진화: `exp 85` 이상
- 졸업: 최종 진화체에서 `exp 100`

### 5.2 2단 진화

- 진화: `exp 50` 이상
- 졸업: 최종 진화체에서 `exp 100`

### 5.3 무진화

- `exp 50` 이상이면 다음 포켓몬 선택 가능

## 6. Pokemon Selection

- 트레이너는 동시에 포켓몬 1마리만 보유한다. 중간 교체는 불가능하다.
- 최초에는 스타터 3마리 중 1마리 선택한다.
- **졸업 조건**
  - 다단 진화 종: 최종 진화체에서 `exp 100`
  - 무진화 종: `exp 50`
- 졸업하면 **졸업 모달**이 학습 화면 위에 열린다.
- **후보 풀 룰**
  - 일반 wave: 미등록 일반 1세대 1차 진화체(또는 무진화 종) 중 랜덤 3마리.
  - 풀 크기 < 후보 수면 풀 그대로 노출.
  - 풀 크기 = 1이면 **선택창 없이 자동 해금** (안내만 보여주고 새 인스턴스로 즉시 시작).
  - 풀이 비면 다음 wave로 자동 전환. 풀 바닥 = 단계 종료 시점이라 후보 중복 허용 같은 fallback 룰은 두지 않는다.
- **이브이 정책**
  - 이브이 분기 진화 시 쥬피썬더/샤미드/부스터 중 유저가 직접 선택한다.
  - 도감 등록은 진화체 단위(샤미드·쥬피썬더·부스터 각각).
  - 이브이는 도감 미완성 분기가 남아 있는 한, 졸업 모달의 후보 풀에 다시 등장할 수 있다 (다른 분기 진화체 도감 채우기 위함).

## 7. Pokedex

- 한 번이라도 획득하면 즉시 도감 등록
- 진화한 형태도 별도 등록
- 지역 도감은 포획 여부와 별개로 한 번이라도 조우한 포켓몬을 체크한다.
- 이브이는 한 번 조우하면 이브이가 출현하는 3개 지역 도감에 모두 체크한다.
- 메타몽은 한 번 조우하면 6개 지역 도감에 모두 체크한다.
- 장기 목표는 1세대 도감 확장

## 8. Legendary Rules

- 일반 지역 출현 목록에서 항상 제외한다:
  - `프리저`
  - `썬더`
  - `파이어`
  - `뮤츠`
  - `뮤`

- 일반 1세대 도감 146종을 등록하면 전설의 새 3종이 각 지역에서 해금된다.
  - `썬더`: 물안개 해안
  - `파이어`: 용암 동굴
  - `프리저`: 얼음 궁전
- 전설의 새 3종을 모두 등록하면 현대 도시에서 `뮤츠`가 해금된다.
- 해금된 전설 포켓몬은 해당 지역에서 조우 성공 후 `1%` 확률로 출현한다.
- 뮤츠까지 150종을 등록하면 `뮤` 돌발 이벤트 팝업을 노출한다.
- 뮤는 지역별 확률 추첨에서 제외한다.
