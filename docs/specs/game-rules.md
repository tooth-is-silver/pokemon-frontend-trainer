# Game Rules

## 1. Stats

- 공통 스탯 4개 사용
- `hp`
- `attack`
- `defense`
- `speed`
- 각 스탯 최대값은 `100`

## 2. Rewards

- 첫 정답 시 각 스탯 `+5`
- 같은 문제 재정답 시 각 스탯 `+1`
- 오답은 보상 없음
- 일반 성장과 진화는 `스탯` 기준

## 3. Items

- `연속 정답 10개` 달성 시 열매 1개 지급
- 열매는 즉시 자동 적용
- 열매는 랜덤 지급
- 각 열매는 해당 스탯 `+5`

열매 매핑:

- `오랭열매`: `hp`
- `무화열매`: `attack`
- `나나열매`: `defense`
- `배리열매`: `speed`

## 4. Evolution

- 진화는 `특정 스탯 기준`으로 판정
- 조건 충족 시 자동 진화하지 않고 선택지 제공
- 진화 보류 가능

### 4.1 3단 진화

- 1차 진화: 4스탯 모두 `50` 이상
- 2차 진화: 4스탯 모두 `85` 이상
- 졸업: 최종 진화체에서 4스탯 모두 `100`

### 4.2 2단 진화

- 진화: 4스탯 모두 `50` 이상
- 졸업: 최종 진화체에서 4스탯 모두 `100`

### 4.3 무진화

- 4스탯 모두 `50` 이상이면 다음 포켓몬 선택 가능

## 5. Pokemon Selection

- 최초에는 스타터 3마리 중 1마리 선택
- 최종 진화체 졸업 상태에서 다음 정답을 맞히면 신규 포켓몬 선택 UI 오픈
- 신규 포켓몬 선택 시 후보 2마리 중 1마리 선택
- 중복 선택은 기본적으로 막음
- 선택 가능한 신규 포켓몬이 없을 때만 중복 허용
- 이브이 계열은 동일 종 복수 보유 허용
- 이브이 분기 진화 시 쥬피썬더/샤미드/부스터 중 유저가 직접 선택

## 6. Pokedex

- 한 번이라도 획득하면 즉시 도감 등록
- 진화한 형태도 별도 등록
- 장기 목표는 1세대 도감 확장

## 7. Legendary Rules

- 일반 선택 후보에서 제외:
  - `파이어`
  - `썬더`
  - `프리저`
  - `뮤츠`
  - `뮤`

- 일반 1세대 도감 완성 후 전설 선택창 오픈
- 1단계: `파이어`, `썬더`, `프리저`
- 2단계: 위 3마리 모두 `100` 졸업 후 `뮤츠`
- 3단계: `뮤츠` 졸업 후 `뮤`
