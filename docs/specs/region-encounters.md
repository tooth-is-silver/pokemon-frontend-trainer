# 지역별 조우 정책

## 1. 판정 순서

1. `탐색하기` 1회마다 기본 `50%` 확률로 조우 성공 여부를 판정한다.
2. 조우에 성공하면 선택한 지역의 희귀도 또는 고정 출현 슬롯을 추첨한다.
3. 희귀도 슬롯이 선택되면 해당 목록 안에서 포켓몬 1마리를 균등 추첨한다.

화면에 표시하는 개별 확률은 소수점 둘째 자리까지 반올림한다. 실제 계산은 반올림하지 않은
`희귀도 확률 / 해당 희귀도 포켓몬 수`를 사용한다.

## 2. 공통 규칙

- 이 문서의 확률은 포켓몬 효과가 적용되기 전 기본값이다.
- 이브이는 `용암 동굴`, `얼음 궁전`, `현대 도시`에서 일반 포켓몬으로 각각 `5%` 확률로 출현한다.
- 메타몽은 모든 지역에서 일반 포켓몬으로 `2%` 확률로 출현한다.
- 이브이를 한 번 조우하면 이브이가 출현하는 3개 지역 도감에 모두 체크한다.
- 메타몽을 한 번 조우하면 6개 지역 도감에 모두 체크한다.
- 지역 도감 체크는 조우 기록이며, 포획으로 등록하는 전체 도감과 구분한다.
- 이브이와 메타몽 외 일반 포켓몬은 한 지역의 출현 목록에만 둔다.
- 전설 포켓몬이 잠겨 있으면 전설 슬롯 `1%`를 해당 지역의 일반 슬롯에 더한다.
- 뮤는 지역 출현 목록에서 제외한다. 뮤츠까지 150종을 등록하면 별도 돌발 이벤트로 노출한다.
- 아래 개별 확률은 전설 슬롯이 활성화된 상태를 기준으로 한다. 전설이 잠겨 있으면 늘어난 일반
  슬롯을 기준으로 개별 확률을 다시 계산한다.

## 5. 실제 탐색 1회 기준

기본 조우 확률이 `50%`이므로 포켓몬별 실제 탐색 확률은 위 확률의 절반이다.

- 이브이: 해당 지역에서 탐색 1회당 `2.5%`
- 메타몽: 모든 지역에서 탐색 1회당 `1%`
- 해금된 전설 포켓몬: 해당 지역에서 탐색 1회당 `0.5%`

예를 들어 초록 평원에서 이상해씨가 나올 확률은 조우 성공 후 `64% / 7`이고,
탐색 1회 기준으로는 `50% × 64% / 7 = 약 4.57%`다.
